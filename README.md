## What it does

`main.ts` writes a single line of the worst possible advice an AI could give
— 109 characters, under the 140-character cap — to `/output/entry.txt`,
where the house gate and judge read it.

## Run

```sh
node main.ts
```

Requires Node 22 or later. No dependencies, no network, no secrets.
